# domino-fox

A Firefox extension: chat with an LLM in the sidebar to extract from and
manipulate the current tab's page — and automate it with LLM-authored
userscripts and multi-tab workflow programs.

This repository hosts **releases only** (signed `.xpi` installers and the
auto-update feed). Source code is not published here.

## Install

1. Download the latest `domino_fox@robinchm-<version>.xpi` from
   [Releases](https://github.com/robinchm/domino-fox/releases).
2. Open it in Firefox (drag onto `about:addons`, or File → Open File).
   Firefox verifies the Mozilla signature and installs it permanently.

Bring your own LLM API keys — configure providers and models in the
extension's Models page after install. All data stays on your machine.
